# WHO IS AI? V1 产品规格

## 核心一句话

玩家在一个精美共享 3D 世界中自由行走，遇到陌生人后最多交流 5 轮，然后判断对方是 **真人、AI，还是不知道**。

## 首版规则

1. 玩家进入共享 3D 世界并自由行走。
2. 靠近陌生人后按 `E` 发起对话。
3. 最多进行 5 轮主动提问，可以提前判断。
4. 判断选项只有：`HUMAN / AI / NOT SURE`。
5. 猜对 `+1`，猜错 `-1`，不知道 `0`。
6. 提交判断后服务器才揭晓身份。
7. 继续寻找下一个陌生人。

## 身份与排行榜

首次进入时浏览器生成 UUID，并保存在 localStorage。服务器以 UUID 保存：昵称、分数、猜对、猜错、不知道、AI 猜对数、真人猜对数和参与次数。下次从同一浏览器打开时继续同一个匿名账户。

全球排行榜首先按总分排序。同分时优先决策率更高的玩家，避免始终选择“不知道”成为最佳策略。

## 真人与 AI

公开世界状态不暴露任何 `isAI` 或 `type` 信息。真人和 AI 使用相同 Avatar 表现和相同公开字段。

AI 在地图中移动，真人不足时仍然有足够的陌生人可遇见。真实模型通过 OpenAI-compatible API 在服务器侧调用；无 Key 时使用内置 Mock AI 进行开发和演示。

## 跨语言

V1 支持 English、中文、Deutsch、Français、Español、日本語语言偏好。

消息存储同时保留：

- 原文
- 原文语言
- 对接收方语言的翻译
- 目标语言

默认显示译文，但接收方始终可以点 `Show original` 查看原文。原因是机器翻译可能抹掉错字、俚语、标点习惯和非母语表达，而这些本身可能是判断真人/AI的重要信号。

真人与 AI 均通过服务器翻译逻辑，不在 UI 上展示“此消息由 AI 翻译”等身份提示。

## 为什么 V1 只有一个地图

首版最需要验证的是核心循环是否有重复吸引力，而不是地图数量。因此 V1 使用一个共享的国际未来广场，让空间语义保持一致：你说“喷泉旁边”，对方也真的能看到同一个喷泉。

V2 再加入北京、纽约、东京等 Parallel Worlds。届时不同客户端可渲染不同世界，但需要明确设定为平行世界，避免双方对环境描述不同看起来像 bug。

## 3D 世界

V1 场景是一个紧凑、可快速相遇的未来国际广场，包括中心喷泉、玻璃亭、茶亭、灯塔、树木、长椅、灯光和周边建筑。世界不追求超大，而追求 20–40 秒内能遇到新的陌生人。

## V1 不做

不做战斗、装备、职业、复杂经济、多个地图、语音、好友系统、皮肤商城和复杂任务。复杂度来自“这个人到底是不是 AI”，不是来自规则。
