# V2 ideas

## Parallel worlds

Players can choose visual worlds such as Beijing, New York, Tokyo or Paris while matching through a shared logical encounter layer. The product should explicitly frame this as **parallel worlds**, so two participants can see different surroundings without creating a continuity bug.

A future encounter can expose a small shared "overlap zone" while each client renders its chosen world. Conversation prompts can include each player's local scene observations.

## Physical Turing tests

Allow simple commands that AI avatars can execute:

- wave
- jump
- sit
- point
- follow
- turn around

This expands the test from language to embodied spatial understanding.

## Additional rankings

- Best Detectives
- Best Impostors (humans most often mistaken for AI)
- Fastest correct detection
- AI model pass rate (only if disclosure policy is clear)

## Account claiming

Bind an existing anonymous UUID to email, Apple or Google so score survives browser changes.

## Voice

Add voice only after text moderation, latency, translation and identity-fairness questions are solved.
